## FTP usefull command 

```bash
# common commands inside ftp prompt:
ls                # list files (short)
dir               # detailed list
pwd               # print server working dir
cd <dir>          # change remote dir
lcd <dir>         # change local dir
get <file>        # download file
mget *.txt        # download multiple files (confirm per file)
put <file>        # upload file
mput *.txt        # upload multiple files
delete <file>     # delete remote file
mkdir <dir>       # create remote directory
rmdir <dir>       # remove remote directory (must be empty)
rename old new    # rename remote file
binary            # set binary mode (important for non-text files)
ascii             # set ascii mode
quit              # exit
 ```
Using curl
```bash
# download a file (anonymous)
curl -O ftp://10.10.10.5/notes.txt

# with credentials
curl -u user:pass -O ftp://10.10.10.5/secret.bin

# list directory 
curl -l ftp://10.10.10.5/     

# upload file
curl -T localfile.txt -u user:pass ftp://10.10.10.5/remote.txt

 ```
