## [Forever remembered - missed]

**Platform:** CSCBE 2024  
**Category:** Cryptography  
**Difficulty:**  Easy  

## TL;DR

A close friend recently passed away, a note was found nearby, we would like you to figure out what it says.


## Goal

- Retrieve the original message

## Description

challenge using base64 and binary encoding with substitution of numbers in binary 0,1 -> 1,2

## steps

We have a txt file with a string containing only  1 and 2 

1) Replace 1 with 0 and 2 with 1 

easy with python 

```bash
string = txt.replace("1", "0")
string2 = string.replace("2", "1")
 ```
2) Decode the message with base 64
